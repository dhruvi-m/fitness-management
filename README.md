## ✨ Features

👤 **Client Management**
- Phone-number based registration
- Existing client detection
- Unique Client ID
- Edit / Delete client
- Joining date and fitness details

🏋️ **Workout Plans**
- Manual workout creation
- AI-generated workouts
- Edit / Delete
- Workout PDF

🥗 **Diet Plans**
- Manual diet creation
- AI-generated diets
- Edit / Delete
- Diet PDF

📈 **Progress Tracking**
- Weekly / Monthly updates
- Weight and body measurements
- Workout & diet adherence
- Progress graph
- Progress score /100
- Weight-loss / gain analysis

🤖 **AI Analysis**
- Progress summary
- Strengths
- Areas to improve
- Recommendations

📸 **Progress Photos**
- Front / Back / Left / Right
- Weekly and monthly tracking

📄 **Complete Fitness Report**
- Client details
- Current workout
- Current diet
- Progress history
- AI analysis
- Recommendations
- Photos
- Downloadable PDF

📊 **Data Center**
- Total clients
- New clients
- Workout / diet counts
- Progress / photo / PDF counts
- Excel-compatible CSV export


## 🛠️ Technology

**Python • Flask • SQLAlchemy • HTML • CSS • JavaScript • Chart.js • Hugging Face AI • ReportLab • GitHub • Render**


## 🔄 System Flow

**Client → Workout → Diet → Progress → Photos → AI Analysis → PDF Report**
