# 💪 Fitness Management System

> 🚀 AI-powered fitness management platform for trainers and coaches.

🌐 **Live Demo:** https://fitness-management-ospb.onrender.com  
💻 **GitHub:** https://github.com/dhruvi-m/fitness-management

## ✨ Features

👤 **Client Management**
- Phone-number based client registration
- Existing client detection
- Unique Client ID
- Edit / Delete client
- Joining date and fitness details

🏋️ **Workout Plans**
- Manual workout creation
- AI-generated workouts
- Edit / Delete plans
- Workout PDF generation

🥗 **Diet Plans**
- Manual diet creation
- AI-generated diets
- Edit / Delete plans
- Diet PDF generation

📈 **Progress Tracking**
- Weekly / Monthly updates
- Weight and body measurements
- Workout & diet adherence
- Progress graph
- Progress score /100
- Weight-loss / gain analysis

🤖 **AI Analysis**
- Progress summary
- Strengths
- Areas to improve
- Next-step recommendations

📸 **Progress Photos**
- Front / Back / Left / Right photos
- Weekly and monthly tracking

📄 **Complete Fitness Report**
- Client details
- Current workout
- Current diet
- Progress history
- AI analysis
- Recommendations
- Progress photos
- Downloadable PDF

📊 **Data Center**
- Total clients
- New clients
- Workout / diet counts
- Progress / photo / PDF counts
- Latest client information
- Excel-compatible CSV export

## 🛠️ Technology

**Python • Flask • SQLAlchemy • HTML • CSS • JavaScript • Chart.js • Hugging Face AI • ReportLab • GitHub • Render**

## 🔄 System Flow

Client → Workout → Diet → Progress → Photos → AI Analysis → PDF Report
